# Superstore Sales Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Superstore sales dataset. The goal is to uncover insights into product performance, regional sales trends, and profitability to help the business make data-driven decisions.

## 🛠️ Tools & Technologies Used
- **Python** (Programming Language)
- **Pandas** (Data Manipulation)
- **Matplotlib & Seaborn** (Data Visualization)

## 📊 Key Insights
- **Top Category:** Technology is the highest-selling category, generating over 836K in sales.
- **Profitability Issue:** While Furniture has high sales, its profit margin is significantly lower, likely due to heavy discounts.
- **Regional Performance:** The West region leads in total sales, whereas the South region has the lowest sales.

## 📁 Repository Structure
- `Superstore_Sales_Analysis_Rashmit (1).ipynb`: Jupyter Notebook containing data cleaning, analysis, and visualizations.
- `SampleSuperstore.csv`: The raw dataset used for this analysis.
